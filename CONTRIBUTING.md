# Contributing

Tenebris Forge follows the engineering standard in
[brunolemosdl/.github](https://github.com/brunolemosdl/.github/blob/main/CONTRIBUTING.md):
work starts from an issue, branches are `<type>/<task-id>/<scope>/<short-description>`,
commits are `<type>(<scope>): [<task-id>] <short description>`, and pull requests follow the
template here and pass the shared policy check.
